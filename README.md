# AI Image Forgery Detection System

## 📌 Overview
This project detects whether an image is REAL or FAKE using digital image forensics and machine learning techniques.

## ⚙️ Technologies Used
- Python
- Flask (Backend)
- HTML, CSS, JavaScript (Frontend)
- Scikit-learn (Machine Learning)
- Pillow (Image Processing)

## 🔍 Features
- Upload image through web interface
- Error Level Analysis (ELA)
- Noise Analysis
- Heatmap visualization
- Edge detection
- ML-based classification (REAL / FAKE)
- Confidence score output

## 🧠 Machine Learning Model
- Random Forest Classifier
- Features: ELA, Noise, Uniformity, DCT

## ▶️ How to Run
pip install flask numpy pillow scikit-learn  
python app.py  

Then open: http://127.0.0.1:5000
